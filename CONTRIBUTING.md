# Contributing to Mycelium

Thank you for helping grow this network.

## Ways to contribute
- Write or review RFCs in `protocol/rfcs`
- Test firmware on supported boards
- Improve documentation
- Report security issues responsibly
- Join field testing pilots
- Translate docs into local languages

## Process
1. Open an issue to discuss significant changes first.
2. Fork and create a feature branch.
3. Add tests or documentation where relevant.
4. Submit a pull request.

## Community principles
- Assume good faith.
- Respect local knowledge and indigenous data sovereignty.
- No surveillance features without public ethical review.
